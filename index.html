Modding Guide

A mod is distributed as a .zip containing manifest.json and icon.png. The ZIP may wrap everything in one top-level folder. JavaScript can register content, subscribe to gameplay hooks, change rules, add localization, patch exposed APIs, and create complete mechanics.

{
  "id": "my-mod",
  "name": "My Mod",
  "version": "1.0.0",
  "gameVersion": ">=1.9.2",
  "main": "main.js",
  "icon": "icon.png",
  "permissions": ["javascript"]
}

main.js receives DK, mod, module, and exports. Export preload(DK) for content registration and init(DK) for logic that needs the running game.

Share mods anywhere you like, then install the downloaded package with Import ZIP. Keeping discovery outside the game makes the manager faster, clearer, and easier to trust.

Useful APIs: DK.events, DK.register, DK.content, DK.addContent(), DK.mergeContent(), DK.rules, DK.i18n, DK.files, DK.storage, and DK.patch().

Custom JavaScript runs with the same browser privileges as Dungeon Knight. Only install code you trust.

    NODE EDITOR TUTORIALBuild mechanics as event → selection → direction → action

    1 · Add and connect nodes

    1. Open Weapon Advanced or Bullet Advanced.
    2. Tap Library on mobile, then tap the + beside a node. If a node is selected, Guided mode automatically connects the new node.
    3. In Guided mode, use each node's Continue to… menu. This fixes mobile drag-connect problems. Choose Connections: Ports only when you want manual wiring.
    4. Edit common values directly inside the node. Inspector remains available for search and detailed work.

    2 · Think in four parts

    Eventwhen?Targetswho?Directionwhere?Actionwhat?

    Example: On Bullet Hit → Select Targets → Set Direction → Move Targets. Each node is reusable; none is tied to one weapon.

    3 · Your AOE movement example

    1. Add On Bullet Hit.
    2. Add Select Targets: Target source = Enemies In Area, Center = Impact, Radius = 60, Maximum targets = 64.
    3. Add Set Direction: Direction source = Bullet Travel.
    4. Add Move Targets: Target = Selected Targets, Movement direction = Along Direction, Distance = the push distance you want.
    5. Connect them in that order. The enemy hit and every enemy inside 60 px move in the bullet's travel direction.

    4 · Aimed child projectile

    On Bullet Hit → Select Targets → Spawn Projectile → Set Projectile Target

    Set Select Targets to Closest Enemy. In Spawn Projectile choose Origin = Impact and Direction = Toward Selected Target. Set Projectile Target to Selected Target if it should keep homing after launch.

    5 · Variables and safe properties

    Use Get Target Property to read HP, position, speed, damage, or another allowed value. Store it in a named variable. Math and Compare can transform or test it. Set Target Property changes only the listed safe properties, preventing an invalid graph from accessing the game engine.

    6 · Delays and validation

    Delay waits once for the exact configured milliseconds before continuing. Timer repeats a connected branch. Both use the elapsed-time simulation wrapper. Use Run Validation before Save or Test; invalid connections and incomplete nodes are blocked instead of crashing gameplay.

    7 · Flow, values, and debugging

    Sequence runs numbered branches. Merge Flow rejoins mutually-exclusive routes. Blue dashed wires carry values; solid wires carry execution. After Test Weapon, executed nodes receive a visible check highlight. Seeded Random Chance gives repeatable tests.
